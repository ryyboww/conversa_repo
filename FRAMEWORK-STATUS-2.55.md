# Framework Status — 2.55.0

This release preserves the Astro 5.13.5 / TypeScript 5.9.2 framework baseline and the complete 2.54 responsive/publication candidate.

The only public-facing change is a Home-page editorial image refresh: the supplied `an_objective_strategy.png` illustration is used for Featured Publication, and the supplied `talk_is_cheap.png` illustration is used for Featured Essay. Publication records, blog metadata, routes, copy, responsive geometry, forms, and operational controls remain unchanged.

A local `npm run check` and `npm run build` are used to confirm the updated source before packaging.
