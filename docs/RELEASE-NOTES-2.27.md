# 2.27 Release Notes

## Added

- consolidated Project Command Center;
- revocable, expiring client project portals;
- client-safe status, milestone, invoice, agreement/change-order, and document views;
- project milestones with optional client visibility;
- manual and opt-in automatic milestone reminders;
- opt-in automatic invoice reminders;
- scheduled reminder deduplication and weekend suppression;
- closeout checklist;
- final-deliverable acknowledgment;
- retention-review dates and legal/administrative holds;
- operator retention-review notifications;
- archive synchronization back to the Project Registry.

## Preserved boundaries

- professional services do not create HubSpot Deals;
- portal access does not change agreement or payment status;
- client acknowledgment confirms receipt/availability only;
- reminder automation is off until enabled per project;
- no automatic deletion occurs at a retention-review date;
- payment credentials are never collected by Convera;
- large or especially sensitive document exchange retains the external-secure-upload option introduced in 2.26.
