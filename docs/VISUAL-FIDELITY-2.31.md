# 2.31 — Approved Homepage Fidelity

## Visual authority

`design-reference/homepage-approved.png` is the authority for homepage composition. The earlier implementation shown in `design-reference/homepage-before-2.31.png` is retained only to make the corrected differences explicit.

## Non-negotiable corrections

1. **Persistent brand** — the header is sticky and the Brand component is never hidden, faded, translated, or replaced during scroll.
2. **Compact header** — desktop target is roughly 82px; primary navigation mirrors the approved mockup. Support is not promoted as a large header button.
3. **Compact hero** — desktop target is 380–430px, not a viewport-height opening screen.
4. **Horizontal editorial composition** — headline, portrait, and founder quote are composed together rather than as three unrelated blocks.
5. **Immediate second band** — Featured Publication and Make a Difference appear directly beneath the hero.
6. **Three-column inquiry band** — Social Perspectives, Workplace Culture, Organizational Strategy.
7. **Compact footer** — logo, central quote, navigation/social links in one contained row.
8. **Tighter scroll rhythm** — desktop homepage should read as a connected editorial canvas, not large isolated panels.

## Content / operations boundaries

This patch changes visual presentation only. It does not remove or alter the 2.22–2.30 professional workflow: Contact, secure Intake, Project #s, proposals, agreements, billing, project portal, security, attribution, or internal operations remain intact.
