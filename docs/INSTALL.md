# Convera Strategies 2.33.0 — Installation

1. Back up the current project directory.
2. Extract this ZIP.
3. Copy its contents into the root of the Convera project and merge folders.
4. Replace matching files when prompted.
5. Run:

```powershell
npm run check
npm run build
npm run dev
```

6. Review the homepage at desktop, tablet, and mobile widths before deployment.

## Intended visual changes

- Header logo remains visible with no scroll-state transformation.
- Theme control is moon icon only; no visible Theme label.
- Desktop hero height is approximately 315–350px and headline scale is reduced about 25% from 2.32.
- Featured Publication, Support, and Areas of Inquiry are tightened into a deliberate editorial rhythm.
- Footer navigation and founder catchphrase are removed.
- Footer logo is smaller.
- Footer descriptor remains one line: `Social Perspectives · Workplace Culture · Organizational Strategy`.
