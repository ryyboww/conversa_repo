# Launch Growth Control — 2.30

Convera's launch objective is not maximum traffic. It is to make public attention legible and direct it into appropriate pathways without collapsing scholarship, community, media, support, and professional work into one sales funnel.

## Public journey

**Discovery → Read/Explore → Follow / Speaking / Contact → manual review → secure Intake when appropriate → Project #**

## Keep separate

- Follow the Work is audience retention, not a professional Intake.
- Speaking/Media is an inquiry category, not automatic scheduling.
- Contact is correspondence and qualification, not project creation.
- Intake is private and manually invited.
- Project # begins the matter.
- Support/contributions remain separate from professional services.
- Store/membership transactions, if introduced later, may use their own commerce/deal workflow.

## Growth questions the system should answer over time

- Which publications lead readers to follow the work?
- Which public topics generate speaking/media inquiries?
- Which sources generate qualified professional Contacts?
- Which referrals become actual Projects?
- Which service/project categories consume the most capacity?
- Which public channels create substantive relationships rather than short-lived traffic?

Do not optimize for a metric merely because it is easy to count.
