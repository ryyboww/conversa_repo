# Convera Strategies 2.40.0 — Publication Rhythm & Content Coherence

This release is a publication-polish pass built on 2.39. It does not change the site architecture.

## Visual rhythm
- Tightens shared interior section and page-hero spacing to better match Home.
- Makes Publications and Essays & Notes cards shorter while preserving readable body text.
- Slightly increases the homepage primary button label for legibility.

## Content coherence
- Replaces process-oriented Community copy with public-facing participation language.
- Adds FAQPage structured data to Work With Convera.
- Rewrites the root release manifest around the current Contact → manual review → private Intake workflow.
- Removes stale audit-result snapshots from older versions so release documentation does not present obsolete status.

## Preserved
- Primary navigation and approved homepage composition.
- Company-first About and separate Founder Profile.
- Separate formal Publications and Essays & Notes archives.
- Public-ready/draft controls for migrated essays.
- Sitewide restrained reveal behavior and reduced-motion fallback.
- Private Intake and project-operations boundary.
