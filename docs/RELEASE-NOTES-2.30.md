# Release Notes — 2.30.0

## Launch Integration & Growth Control

2.30 does not introduce another public product or another private project subsystem. It connects the public visibility layer built in 2.29 to the existing Convera operating architecture.

### Added

- reusable visibility navigation/footer components;
- provider-neutral public journey event bridge;
- event-aware Publication CTA;
- Privacy attribution disclosure component;
- event dictionary;
- SEO/sitemap launch review;
- deploy-time public journey audit;
- end-to-end public-to-private launch test;
- launch growth-control framework.

### Preserved boundaries

- Contact and Intake remain separate;
- Intake remains private and manually invited;
- public forms do not create Projects;
- services do not create HubSpot Deals;
- Follow the Work does not imply third-party enrollment;
- attribution remains first-party/session-level;
- no analytics provider is installed by this patch;
- Support/contributions remain separate from professional services.
