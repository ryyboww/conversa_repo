# Convera Strategies 2.28.0 — Release Notes

## Operations Intelligence & Portal Security

### Added

- one-time email verification for client project portals;
- expiring verified portal sessions;
- OTP hashing, throttling, and temporary lockout;
- operator visibility into portal verification status;
- Operations Intelligence dashboard;
- project status, aging, workload, priority, source/referral, deadline, billing, and portal-security summaries;
- per-project priority, capacity weight, target completion date, source detail, and referral source;
- operator-configurable portfolio capacity units.

### Preserved

- Contact and Intake remain separate;
- Intake remains manually invited;
- Intake creates Project # only after validated submission;
- estimates remain non-contractual;
- agreements, invoices, payments, and documents remain separate administrative objects;
- professional-service HubSpot Deals remain disabled;
- automatic reminders remain opt-in by Project #;
- retention review never automatically deletes project records.

### Security wording

Two-step portal email verification is not represented as independent-factor MFA.
